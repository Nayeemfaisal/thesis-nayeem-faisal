# Academic source workspace

This directory keeps the supplied THA source materials beside the thesis website without presenting generated text as part of the submitted thesis.

## THA LaTeX template

The `tha-template` directory contains the official template components from `abschlussarbeit-main.zip`. `Nayeem-Faisal-THA-Workspace.tex` is a minimal build preview configured with the thesis title, author, programme, faculty, supervisor, and submission date already documented in this repository.

Fields that were not supplied, including the matriculation number, private postal address, telephone number, and university email address, are marked as not stored publicly. Replace those values only in a private copy if a formal source document is required.

The preview does not reproduce or replace the submitted thesis. The final PDF published on the thesis website remains authoritative.

## Exposé template

`expose/Vorlage Expose.docx` is the supplied blank Word template preserved unchanged. It has not been filled automatically, because doing so would create new academic wording that is not part of Nayeem Faisal's original submitted work.
